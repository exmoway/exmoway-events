# exmoway-events

Event lists for the "Events & ideas" section of [exmoway.com](https://www.exmoway.com).

- Updated every day by a scheduled Claude task that follows [`CLAUDE.md`](CLAUDE.md).
- The website downloads these files once a day and checks them before showing them
  (same rules as `node tools/validate.mjs`). Anything that fails the check is not shown.
- Website owner: to stop updates, use **Admin → Events → Pause automatic updates**. To go back
  to the previous list, use **Undo last update** there.

This repository is public on purpose: it contains only public event information — no passwords,
keys or personal data. Never add any.
